# Android 工程

构建、功能与贡献入口见[项目 README](../README.md)。

- `app/src/main/java/com/sinkabyss/framewatermark/`：界面、逐图会话、绘制、素材与数据备份。
- `app/src/main/res/`：应用资源与离线机型名称表。
- `app/src/test/`：宿主规则、Android Canvas 与 Compose 检查。
- `gradle/wrapper/`：固定版本的 Gradle Wrapper。

验证边界见[验证说明](../docs/validation.md)，资源来源见[第三方说明](../THIRD_PARTY_NOTICES.md)。
